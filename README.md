# Rock-Paper-Scissors Game

A simple command-line Rock Paper Scissors game built using Python[span_1](start_span)[span_1](end_span).

## About This Project
I built this project as a **First-Year BCA (Bachelor of Computer Applications) student** to practice core Python programming concepts—including user input handling, conditional logic (`if-elif-else`), loops, and the `random` module.

## Features
* Play against the computer with randomized choices
* Instant win/loss/tie result tracking
* Beginner-friendly terminal interface

## How to Run
1. Make sure you have Python installed on your system.
2. Clone or download this repository.
